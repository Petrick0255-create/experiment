1. 실험 아카이브 관리 스프레드시트를 엽니다.
2. 확장 프로그램 → Apps Script를 누릅니다.
3. 기본 Code.gs 내용을 모두 지우고 제공된 Code.gs를 붙여넣습니다.
4. 저장한 뒤 exportArchiveJson 함수를 한 번 실행하고 권한을 승인합니다.
5. 스프레드시트를 새로고침하면 상단에 ‘아카이브 관리’ 메뉴가 생깁니다.

[시트 → JSON]
아카이브 관리 → 시트 → JSON 내보내기
지정 폴더의 experiment-archive.json 파일을 새로 만들거나 같은 파일을 갱신합니다.
기존 JSON의 준비물과 실험지 설계 내용은 ID를 기준으로 보존됩니다.

[JSON → 시트]
수정한 파일명을 experiment-archive.json으로 유지해 지정 Drive 폴더에 올립니다.
기존 파일이 있다면 새 파일을 별도로 만들지 말고 기존 파일을 교체하는 것이 안전합니다.
아카이브 관리 → JSON → 시트 갱신을 실행합니다.
갱신 전 backup-날짜-experiment-archive.json 파일이 자동 생성됩니다.

[페이지]
index.html, style.css, app.js, experiment-archive.json을 같은 exp-archive 폴더에 둡니다.
페이지에서 수정한 뒤 ‘JSON 내려받기’를 누르면 파일명이 experiment-archive.json으로 저장됩니다.
