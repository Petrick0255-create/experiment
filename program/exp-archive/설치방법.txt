1. 실험 아카이브 관리 스프레드시트를 엽니다.
2. 확장 프로그램 → Apps Script를 누릅니다.
3. 기존 Code.gs를 모두 지우고 제공된 Code.gs 전체를 붙여넣어 저장합니다.
4. setupArchiveSheets 함수를 한 번 실행하고 권한을 승인합니다.
5. 스프레드시트를 새로고침합니다.

[동기화 키]
1. 시트 상단의 아카이브 관리 → 동기화 키 만들기/확인을 누릅니다.
2. 표시된 키를 복사합니다.
3. 키는 홈페이지 코드에 직접 적지 말고 홈페이지의 연결 설정에 입력합니다.

[웹 앱 배포]
1. Apps Script 우측 상단 배포 → 새 배포를 누릅니다.
2. 유형은 웹 앱을 선택합니다.
3. 다음 사용자로 실행: 나
4. 액세스 권한: 모든 사용자
5. 배포 후 표시되는 /exec 주소를 복사합니다.
6. 홈페이지의 연결 설정에 웹 앱 주소와 동기화 키를 입력합니다.

[홈페이지에서 동기화]
동기화 및 백업 버튼을 누르면 다음 순서로 실행됩니다.
1. 기존 Drive JSON의 모든 실험을 백업 시트에 추가
2. 수정된 JSON으로 Drive의 experiment-archive.json 교체
3. 실험 마스터 시트 갱신
4. 최근 30일 안에 생성·수정된 실험을 새로운 실험 시트에 최근 순으로 정리

[JSON 가져오기]
홈페이지의 JSON 가져오기 버튼은 PC 파일을 선택하는 버튼이 아닙니다.
현재 실험 마스터 시트를 즉시 읽어 홈페이지 목록과 Drive JSON을 함께 갱신합니다.
시트에서 난이도나 학년 등을 직접 수정한 뒤 JSON 가져오기를 누르면 바로 반영됩니다.

[주의]
Apps Script 코드를 수정한 뒤에는 배포 → 배포 관리 → 수정 → 새 버전으로 다시 배포해야 합니다.
기존 /exec 주소를 그대로 사용하려면 새 배포가 아니라 기존 배포를 새 버전으로 갱신하세요.
동기화 키가 노출되면 아카이브 관리 → 동기화 키 다시 만들기로 교체하세요.
