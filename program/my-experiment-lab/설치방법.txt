[생성된 관리 시트]
https://docs.google.com/spreadsheets/d/1X_IIQQ37KcksWBoK2BexyEv0_Is8VJaPbBJg7BiD2xk/edit

시트는 지정한 Google Drive 폴더 안에 생성되어 있습니다.


[1. Apps Script 설치]
1) 위 스프레드시트를 엽니다.
2) 확장 프로그램 → Apps Script를 누릅니다.
3) 기본 코드를 모두 지우고 이 ZIP의 Code.gs 전체를 붙여넣습니다.
4) 저장합니다.
5) Apps Script 편집기에서 setupLabSheets 함수를 한 번 실행하고 권한을 승인합니다.


[2. 동기화 키 만들기]
1) 스프레드시트를 새로고침합니다.
2) 상단 메뉴 나의 실험실 → 동기화 키 만들기/확인을 누릅니다.
3) 표시된 키를 복사합니다.


[3. 웹 앱 배포]
1) Apps Script 우측 상단 배포 → 새 배포를 누릅니다.
2) 유형은 웹 앱을 선택합니다.
3) 실행 사용자는 나, 액세스 사용자는 모든 사용자로 설정합니다.
4) 배포 후 /exec로 끝나는 웹 앱 주소를 복사합니다.
5) 코드를 수정한 뒤에는 배포 → 배포 관리 → 수정 → 새 버전으로 다시 배포해야 합니다.


[4. 홈페이지 연결]
1) index.html, style.css, app.js를 원하는 홈페이지 폴더에 넣습니다.
2) 홈페이지에서 연결 설정을 누릅니다.
3) Apps Script 웹 앱 주소와 동기화 키를 입력합니다.
4) 이후 시트 동기화를 누르면 기존 데이터가 백업된 뒤 내 실험, 배치, 준비물 체크가 저장됩니다.


[아카이브 참고 실험]
- 기존 실험 아카이브 관리 시트의 실험 마스터를 직접 읽습니다.
- 숨겨진 이미지 파일 시트에서 실험지 주소도 함께 읽습니다.
- 별도의 실험 아카이브 복제 시트는 만들지 않습니다.
- 나의 실험실 페이지에서 시트 정보를 불러오거나 동기화하면 최신 아카이브 목록도 함께 가져옵니다.
- 참고 실험 ID가 같은 내 실험의 참고 실험명은 최신 이름으로 갱신됩니다.
- 아카이브에서 실험을 선택하면 편집 화면 오른쪽에 원본 분류 정보와 전체 실험지 이미지가 표시됩니다.
- JSON 불러오기는 시트 연결 전 임시 사용이나 오류 복구용입니다.
- 참고 실험의 ID와 이름만 저장하며 실험지 이미지는 내 실험 데이터에 복사하지 않습니다.


[데이터 운영]
- 내 실험 편집, 커리큘럼 배치, 준비물 체크는 먼저 브라우저에 임시 저장됩니다.
- 시트 동기화를 눌러야 Google 시트에 반영됩니다.
- 동기화 직전의 전체 데이터는 백업 시트에 자동 보관됩니다.
- 다른 컴퓨터에서는 연결 설정 후 시트 동기화를 누르면 시트 데이터를 불러옵니다.
- 처음 Apps Script를 실행할 때 기존 실험 아카이브 관리 시트에 대한 접근 권한을 추가로 승인해야 할 수 있습니다.
- 시트 열 제목은 Apps Script가 사용하므로 변경하지 않는 것이 안전합니다.
